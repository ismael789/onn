# Avisos de terceros

## Catálogo de controles infrarrojos

`ir_tv_catalog.json` contiene datos transformados de
[Lucaslhm/Flipper-IRDB](https://github.com/Lucaslhm/Flipper-IRDB), revisión
`d126fb1b6f1e114c52b4a8c19839ea65e3a9c24d`, publicados bajo CC0 1.0.

Las conversiones de protocolos se contrastaron con el código de
[Flipper Zero Firmware](https://github.com/flipperdevices/flipperzero-firmware)
y [Home Assistant infrared-protocols](https://github.com/home-assistant-libs/infrared-protocols).
